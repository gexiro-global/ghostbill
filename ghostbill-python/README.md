# ghostbill

`ghostbill` is the planned official Python SDK for GhostBill, a privacy-first non-custodial Monero payment processor.

This repository snapshot is a pre-alpha scaffold. It is not functional yet: C1 only includes package metadata, error classes, event constants, and client constructors.

The intended install command will be:

```bash
pip install ghostbill
```

The package is not yet published on PyPI.

Canonical GhostBill documentation lives in the main repository:

- [API reference](https://github.com/gexiro-global/ghostbill/blob/main/docs/API.md)
- [Webhook integration guide](https://github.com/gexiro-global/ghostbill/blob/main/docs/WEBHOOK_DEBUGGING.md)
- [Merchant cookbook](https://github.com/gexiro-global/ghostbill/blob/main/docs/MERCHANT_COOKBOOK.md)
